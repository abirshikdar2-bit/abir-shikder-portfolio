## 🌟 Key Features

- **Framer Vexoo Inspired Aesthetics**: Ultra-minimal dark theme (`#08090C`), frosted glassmorphism borders (`rgba(255,255,255,0.08)`), and ambient radial glow.
- **Dynamic Bento Grid**: Responsive grid architecture highlighting experience, active stack, and location.
- **Live Asia/Dhaka Clock**: Synchronized real-time status pill reflecting local Bangladesh timezone.
- **Morphing Dynamic Roles**: Animated smooth text morphing between Full-Stack Web Developer, UI/UX Architect, and Creative Technologist.
- **Interactive Mouse Spotlight**: Real-time cursor tracking radial glow on cards and interactive elements.
- **Case Studies Showroom**: Featuring SaaS Analytics, E-Commerce, Generative AI Studio, and Neo-Fintech applications.
- **Direct Inquiry Channel**: Functional client inquiry form with instant feedback state.

---

## 🚀 Tech Stack

- **Core**: HTML5, Semantic Markup, CSS3 Variables, ES6+ JavaScript
- **Typography**: Inter & Plus Jakarta Sans via Google Fonts, Phosphor Icons
- **Deployment**: Vercel Serverless Edge CDN
- **Version Control**: Git & GitHub

---

## 💻 Local Development

Clone the repository and run any static file server:

```bash
git clone https://github.com/abirshikdar2-bit/abir-shikder-portfolio.git
cd abir-shikder-portfolio
# Run with Python
python -m http.server 8080
# Or with Node.js
npx serve
```

Visit `http://localhost:8080` in your browser.
